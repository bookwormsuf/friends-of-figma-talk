# Friends of Figma talk

A browser presentation of Sufyan’s Friends of Figma talk, based on the current Figma Slides deck.

## Language

**Slide**: One narrative unit in the source Figma deck. An unskipped slide belongs in the presentation sequence.

**Speaker notes**: The presenter’s accompanying words and instructions for a slide, separate from audience-visible slide content. These are also available for public reading.

**Notes view**: The audience window showing the current slide, its speaker notes and the next slide, in place of the slide alone. Slides can be stepped through from it.

**Presenter window**: A separate window with the same layout as the Notes view. It follows the audience window.

**Phone remote**: A page opened on a phone that shows the current slide and its notes and asks the laptop to move. It reaches the laptop over the internet.

**Pairing code**: The long random code in the phone remote's link. Whoever has it can ask the laptop to move.

**Owner**: The one phone the laptop obeys. The first phone to pair becomes the owner.

**Skipped alternative**: A source slide retained as a design option but excluded from the main presentation sequence.

**Source snapshot**: A recorded version of the Figma deck used to build a particular version of the website.

**Layout adjustment**: A slide-specific change to composition, position, size or spacing that leaves its source content intact.

**Spark**: The spiky star-shaped chrome object, the counterpart to the cloud. A cloud stands for a “what if”, a spark for a “try this”. Called `burst` in code.

**Closing animation**: The wordless sequence at the end of the talk in which one cloud is picked out of many and becomes a spark.

**Beat**: One moment in an animation’s story, for example “the centre cloud glows”. Several beats can play on one press of Next.
